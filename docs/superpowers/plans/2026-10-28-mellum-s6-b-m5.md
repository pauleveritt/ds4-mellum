> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resident and streamed MXFP4 Mellum run on the M5 Max. Model-free Metal tests show it, and so do the
preregistered runs: logits against llama.cpp, the Q8_0 no-regression A/B, the Q8_0-vs-MXFP4 comparison, and

report. Then the runs, each judged by [the preregistration](../research/2026-10-28-mellum-s6-b-preregistration.md).

**Tech Stack:** C99 and Objective-C (`ds4.c`, `ds4_metal.m`, `metal/qwen4.metal`), the Metal kernel tests
(`tests/test_mellum_kernels.c`), Homebrew `llama.cpp` 0.7.0's `libllama`, Python 3 stdlib tools, `make`.

### Task 5: The llama.cpp logits driver and the agreement report

**Files:**
- Create: `tools/mellum_llama_logits.c`, `tools/mellum_logits_agree.py`.
- Tests: `tests/test_mellum_logits_agree.py`, plus a model-free argument check of the driver.
- Modify: `Makefile`, targets `tools/mellum_llama_logits` (with `-I` and `-L` from `brew --prefix llama.cpp`)
  and `test-mellum-logits-agree`. `test-mellum` gains only the Python test, so it builds where llama.cpp is
  absent.

**Interfaces:**
- `tools/mellum_llama_logits MODEL TOKENS_FILE PREFIX POSITIONS` reads ids in `tests/mellum_trace`'s token
  format and decodes them in one batch, with logits on for the traced positions and the last. It writes
  `PREFIX.p<N>.logits.f32` and `PREFIX.session.logits.f32` (98,304 f32 each). It exits 2 on bad usage, and on
  any id at or above `llama_vocab_n_tokens`.
- `python3 -I tools/mellum_logits_agree.py A B POSITIONS` prints one JSON object: per-position KL(B ‖ A),
  top-1 equal, near-tie (B's top two within 0.75 nats), mean KL, worst KL and agreement rate.

- [ ] **Step 1: Failing tests.** In `test_mellum_logits_agree.py`, hand-made files as in
  `test_mellum_logits_compare.py`:
  - identical runs give KL 0 and 100% agreement;
  - a swapped top-1 counts as a disagreement;
  - the same swap with B's margin under 0.75 nats counts as a near-tie agreement;
  - a NaN is refused with exit 1.

  The driver check: no arguments, and a model path that does not exist, each exit 2 with a message. Commit:
  `test: an agreement report for two traced Mellum runs`.
- [ ] **Step 2: Implement both. Verify the tests pass, then commit:** `feat: llama.cpp logits at traced
  Mellum positions, and their agreement report`.
